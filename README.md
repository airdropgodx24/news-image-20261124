# news-image-20261124

Entry for the make.fun "Sum up 24 November's world news in one image"
competition. `main.py` draws the whole 1024x1024 news image in code using
only the Python standard library: a hand-written PNG encoder (zlib +
struct) and a tiny 5x7 bitmap font embedded in the file. It covers the
day's biggest stories, NATO's space-defence vow, Nvidia reinstating
Jensen Huang, Ukraine sinking a Russian warship off Libya, the COP31
collapse, Russian missiles in Poland, South Korea's airspace alert and
Mexico's capture of Chapo Isidro, with the FIFA 2031 Women's World Cup
hosts and the Democrats' House majority in the footer strip.
